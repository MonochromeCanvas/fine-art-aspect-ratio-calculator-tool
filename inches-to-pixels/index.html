The simple math

Inches × PPI = pixels.

An 8 × 10 inch print at 300 PPI needs 2,400 × 3,000 pixels. To go the other way, divide pixels by PPI.

Before you print

Size is one part of the picture.

This tool calculates dimensions; it doesn’t resize a file or add detail. Setting a higher PPI here won’t make a small image sharper. PPI describes image resolution; printer DPI describes ink dots.
